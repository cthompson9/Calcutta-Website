---
name: Dated consortium reporting
description: Rules for keeping consortium changes from rewriting historical Calcutta reports.
---

Historical Calcutta reporting must resolve consortium membership at the canonical Calcutta’s deterministic as-of date (normally August 1 of that season). A current-roster reading is available only when deliberately selected.

**Why:** bidders can move between consortiums. Using a bidder’s current affiliation for a historic report silently changes the past after a merger or departure.

**How to apply:** any new report, export, API, or MCP tool that shows consortium totals must default to the Calcutta as-of membership join and label a current-membership alternative clearly. Keep membership intervals non-overlapping for each bidder.
