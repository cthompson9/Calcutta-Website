| Parameter | Definition |
|---|---|
| `season` | Required integer season year |
| `calcuttaId` | Optional positive integer; use existing unambiguous canonical-pool resolution |
| `snapshotId` | Optional positive integer for an immutable successful official-source snapshot; must belong to the resolved pool/season |
| `team` | Optional canonical team code, e.g. ARI; validate rather than silently treating no match as all teams |
| `family` | Optional enum `wins` or `elimination` |
| `ticker` | Optional exact ticker |
| `limit` | Integer 1–200, default 100 |
| `cursor` | Opaque pagination cursor bound to snapshot, filters and last stable `(family, team, ticker)` key |

Default reads resolve the current official source snapshot once. If current display is provisional/pending, expose that state and pending Actuals revision alongside the prior official source; do not label the prior source as current with respect to Actuals. A cursor pins the snapshot so a concurrent promotion cannot mix pages.

Response envelope:

```text
schemaVersion: "1.0"
available: boolean
season, calcuttaId
snapshot: { id, valuationVersionId, asOf, actualsRevision,
            pricingMethodVersion, referencePolicyVersion } | null
currentState: { markType, pendingActualsRevision, usesArchivedOfficial,
                stale, staleReasons[] }
units: { quotePrice: "USD_per_1_USD_payout", probability: "0_to_1",
         valuation: "USD" }
summary: { totalMarkets, freshCount, carriedForwardCount,
           settledCount, unavailableCount }
markets: ReferenceMarket[]
teamValues: TeamValue[]
pagination: { limit, returned, nextCursor }
```

`ReferenceMarket` contains stable `ticker`, `eventTicker`, `provider`, safe `sourceUrl`, `team`, `family`, `outcome` or `strike`, `marketStatus`, observed `bid/ask/last` (each nullable), nullable verified `lastTradeAt`, nullable `quoteCapturedAt`, `referencePrice`, `selectionMethod`, `reasonCodes`, `referenceAcceptedAt`, `referenceSourceSnapshotId`, `referenceSourceTicker`, `carriedForward`, and computed nonnegative `referenceAgeSeconds`. Include `fairProbability` and `probabilityBasis` for that exact contract where the model computes it; otherwise return null with an explicit unavailable reason. A playoff reach probability must not be mislabeled as the probability of elimination in that round.

`TeamValue` contains `team`, `grossTeamValue`, `valuePerOnePercentOwnership`, `fairReachProbabilities`, and the same source snapshot identity. Return values only for teams represented on the page. Full-team gross value is distinct from owner net MTM, cost basis, and Kalshi contract prices. The 1% ownership value is grossTeamValue / 100; it is not a bid/ask execution quote. Historical missing fields stay null; do not reconstruct fake provenance or probabilities.

Use 200 with `available:false`, empty arrays, and a reason when a valid pool has no official reference set. Use 400 for invalid inputs/cursor, 404 for an unknown pool/team or an out-of-scope snapshot, and normal 401/403 for authorization. Valid filters with no matching market return an empty page. Reject conflicting scope rather than falling back to another pool. Sanitize URLs, return an allowlisted projection, and never expose raw provider JSON, credentials or full diagnostics blobs. Use private/no-store caching initially so auth-sensitive data and dynamic age are not cached incorrectly.

REST authentication: reuse existing static MCP/admin token matching helpers for a read-only middleware; accept configured `MCP_API_KEY` or distinct `ADMIN_API_KEY` via Bearer, without granting write authority. Keep existing MCP OAuth audience/scope behavior unchanged; OAuth clients can access the new tool through `/api/mcp`. Do not extend an OAuth token intended for `/api/mcp` to unrelated REST resources without an explicit audience design.

Add the route/schema to OpenAPI, regenerate Zod/client artifacts with `pnpm --filter @workspace/api-spec run codegen`, and validate responses with the generated schema. Do not hand-edit generated files.
